Improved Petri Net Visualization

Changes Implemented

  • ✅ Labels positioned below elements - Changed from y - 20 to y + 28
  • ✅ Enabled transitions highlighted in green - Color #62fa75
  • ✅ Smart enabled detection - Transitions are enabled when all input places have sufficient tokens

Legend

Enabled Transition (Green)
Has sufficient tokens in all input places. Example: t1 is enabled because p1 has 2 tokens (≥1 required)
Disabled Transition (White)
Lacks sufficient tokens in one or more input places. Example: t2 is disabled because p2 has 0 tokens (needs 1)

Test Scenario

  • p1 has 2 tokens → provides input to t1
  • p2 has 0 tokens → provides input to t2
  • t1 needs 1 token from p1 → ENABLED (shown in green)
  • t2 needs 1 token from p2 → DISABLED (shown in white)
  • All labels appear below their respective elements
