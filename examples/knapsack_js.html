🎒 Knapsack Problem - ODE Solver Demo

About this demo: This demonstrates the psolver.js ES module, which replicates the ODE solver functionality from the Julia notebook. It uses the Tsit5 (5th order Runge-Kutta) solver to simulate a Petri net model of the knapsack optimization problem.

Problem Setup

  • Capacity: 15 units
  • Items: 4 items with different weights and values
  • Goal: Maximize value within capacity constraint

Technical Details

  • Solver: Tsit5 (adaptive RK)
  • Format: JSON-LD compatible
  • Module: Pure ES6 JavaScript

Petri Net Model

Items:
• Item 0: weight=2, value=10
• Item 1: weight=4, value=10
• Item 2: weight=6, value=12
• Item 3: weight=9, value=18

How it Works

        

            
    
                
  1. Model Definition: The Petri net is defined in JSON-LD format, compatible with pflow.xyz schema
    2. 
                
  2. ODE Conversion: The Petri net structure is converted to a system of ODEs using mass-action kinetics
    3. 
                
  3. Numerical Solution: The Tsit5 solver (5th order Runge-Kutta with adaptive stepping) integrates the ODEs
    4. 
                
  4. Visualization: Results are plotted using the built-in SVG plotter
    5. 
            

        


        
Code Example

        


import { fromJSON, setState, setRates, ODEProblem, solve, Tsit5, SVGPlotter } from './psolver.js';

// Load model from JSON-LD
const net = fromJSON(knapsackData);

// Set initial conditions and parameters
const initialState = setState(net);
const rates = setRates(net);

// Create and solve ODE problem
const prob = new ODEProblem(net, initialState, [0.0, 5.0], rates);
const sol = solve(prob, Tsit5());

// Plot results
const svg = SVGPlotter.plotSolution(sol, ['value'], {
    title: 'Knapsack Simulation',
    xlabel: 'Time',
    ylabel: 'Tokens'
});
