═══════════════════════════════════════════════════════════════════
MATHEMATICAL ALGORITHM
═══════════════════════════════════════════════════════════════════

Tsit5 Solver (Tsitouras 2011):
   • 7-stage Runge-Kutta method
   • 5th order accurate
   • Embedded 4th order for error estimation
   • Adaptive time stepping with PI controller
   • Safety factor: 0.9
   • Error tolerance: abstol=1e-6, reltol=1e-3

Mass Action Kinetics:
   • Flux = k × ∏(input_concentrations)
   • du/dt = ∑(outflux) - ∑(influx)
   • Stoichiometric coefficients from arc weights

═══════════════════════════════════════════════════════════════════
USAGE EXAMPLE
═══════════════════════════════════════════════════════════════════

import { fromJSON, setState, setRates, ODEProblem, 
         solve, Tsit5, SVGPlotter } from './psolver.js';

// Load Petri net from JSON-LD
const net = fromJSON(petriNetData);

// Set up ODE problem
const prob = new ODEProblem(
    net,
    setState(net),
    [0.0, 10.0],
    setRates(net)
);

// Solve with Tsit5
const sol = solve(prob, Tsit5());

// Generate plot
const svg = SVGPlotter.plotSolution(sol, ['value'], {
    title: 'Simulation',
    xlabel: 'Time',
    ylabel: 'Value'
});
